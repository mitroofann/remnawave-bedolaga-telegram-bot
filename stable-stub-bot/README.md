# Бот-заглушка (Stable VPN → Bulka VPN)

Лёгкий отдельный бот на СТАРОМ токене. На любое сообщение отвечает картинкой нового
бренда, текстом о переезде и кнопкой на нового бота. Есть админ-команда `/broadcast`
для разовой рассылки того же сообщения по всей базе.

## ⚠️ Важно перед запуском

**Останови старый основной бот** на этом токене. Один токен = один polling-процесс;
если запустить заглушку рядом с работающим старым ботом — оба будут конфликтовать.

Порядок: рассылка-приглашение со старого ОСНОВНОГО бота (пока он полный) → остановить
старый основной бот → запустить эту заглушку.

## Настройка

1. Положи логотип Bulka VPN: `assets/bulka_logo.png` (или укажи свой путь в `BULKA_LOGO_PATH`).
2. Скопируй `.env.example` → `.env` и заполни:
   - `BOT_TOKEN` — старый токен.
   - `BULKA_BOT_USERNAME` — username нового бота без `@`.
   - `ADMIN_IDS` — кто может слать `/broadcast`.
   - `DATABASE_URL` — та же БД (только для `/broadcast`; без него заглушка-ответы всё равно работают).

## Запуск

Docker:
```
docker compose up -d --build
docker compose logs -f
```

Или напрямую:
```
pip install -r requirements.txt
python stub_bot.py
```

## /broadcast

Отправь боту `/broadcast` с админского аккаунта — разошлёт сообщение о переезде всем
живым пользователям из базы (с троттлингом, пропуская заблокировавших). Прогресс и
итог придут тебе в ответ. Не-админам команда не отвечает ничем, кроме обычной заглушки.

> Массовую рассылку эффективнее сделать основным старым ботом ДО замены на заглушку.
> `/broadcast` здесь — для «добивания» тех, кто ещё не перешёл.

## Что редактировать

- Текст сообщения — константа `STUB_CAPTION` в `stub_bot.py`.
- Кнопка — функция `_keyboard()` там же.
