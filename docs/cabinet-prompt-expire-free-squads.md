# Промпт для Опуса, работающего над кабинетом (фронт)

Скопируй текст ниже в соседнее окно.

---

В форме создания/редактирования тарифа нужно добавить пару новых полей для фичи
**«Бесплатный доступ после истечения подписки»**. Бэкенд (Web API бота) уже готов — со стороны
фронта нужно только UI + прокидка полей.

## Контекст фичи

Когда подписка истекает, бот снимает у пользователя все серверы в панели (чтобы приложение
показывало корректное «подписка истекла», а не мёртвые хосты). Но для конкретного тарифа можно
вместо этого выдать «бесплатный» сервер и оставить доступ на несколько дней (стимул продлить).

Управляется парой полей тарифа:

- `expire_free_squads: string[]` — список UUID «бесплатных» сквадов (серверов), которые выдаются
  при истечении вместо реальных. Можно несколько.
- `expire_free_days: number` — сколько дней доступен бесплатный сервер после истечения.

**Оба поля работают в паре: фича включается, только если выбран хотя бы один сквад И дней > 0.**
Если список пуст или дней = 0 — при истечении просто снимаются все серверы (поведение по умолчанию).

## Что уже есть на бэкенде

Поля присутствуют в трёх местах API тарифов:

- **GET** `/admin/tariffs/{id}` (`TariffDetailResponse`) → возвращает `expire_free_squads: string[]`
  и `expire_free_days: number`. Там же уже приходит массив `servers` — каждый элемент
  `{ id, squad_uuid, display_name, country_code, is_selected, traffic_limit_gb }`. Это полный
  список доступных серверов; для мультиселекта бери `squad_uuid` (значение) + `display_name` (подпись).
- **POST** `/admin/tariffs` (`TariffCreateRequest`) → принимает `expire_free_squads: string[]`
  (по умолчанию `[]`) и `expire_free_days: number` (по умолчанию `0`, `>= 0`).
- **PUT/PATCH** `/admin/tariffs/{id}` (`TariffUpdateRequest`) → принимает `expire_free_squads:
  string[]` и `expire_free_days: number` (оба необязательные; если прислать — перезапишут значения).

## Что сделать на фронте

1. В форме тарифа добавить блок **«Бесплатный доступ после истечения»**:
   - мультиселект **«Бесплатные серверы»** — варианты из `servers` (подпись `display_name`,
     значение `squad_uuid`);
   - числовое поле **«Дней бесплатного доступа»** (целое, `>= 0`).
2. В отличие от `limit_disabled_squads`, бесплатные сквады НЕ обязаны быть подмножеством
   `allowed_squads` — это может быть отдельный «урезанный/бесплатный» сервер. Показывать в
   мультиселекте весь список `servers`.
3. Предзаполнять из `expire_free_squads` / `expire_free_days` при загрузке тарифа.
4. При сохранении отправлять оба поля в POST/PUT.
5. Подсказать пользователю, что фича включается только при заполнении ОБОИХ полей (сквад(ы) +
   дни > 0). Если выбрано что-то одно — можно показать предупреждение, что фича не активируется.

## Подсказка для пользователя (текст рядом с блоком)

Что-то вроде: «Когда подписка истечёт, вместо полного отключения пользователю выдаётся выбранный
бесплатный сервер на указанное число дней. По истечении этого срока сервер отключается. Если
оставить поля пустыми — при истечении просто снимаются все серверы. Оставьте бесплатные серверы
пустыми, чтобы отключить фичу для тарифа.»

  отдельные поля.
- Не добавлять никаких вызовов к RemnaWave напрямую — только поля в форме тарифа.
