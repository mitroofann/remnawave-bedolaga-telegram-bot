# Промпт для Опуса, работающего над кабинетом (фронт)

Скопируй текст ниже в соседнее окно.

---

В форме создания/редактирования тарифа нужно добавить новое поле — **«Серверы, отключаемые
при исчерпании трафика»** (мультиселект сквадов). Бэкенд (Web API бота) уже готов — со стороны
фронта нужно только UI + прокидка поля.

## Что уже есть на бэкенде

Тариф теперь имеет поле `limit_disabled_squads: string[]` — список UUID сквадов (серверов),
которые гасятся у пользователя при достижении лимита трафика (остальные серверы продолжают
работать, подписка остаётся активной). Это ПОДМНОЖЕСТВО уже существующего `allowed_squads`.

Поле присутствует в трёх местах API тарифов:

- **GET** `/admin/tariffs/{id}` (`TariffDetailResponse`) → возвращает `limit_disabled_squads: string[]`.
  Там же уже приходит массив `servers` — каждый элемент `{ id, squad_uuid, display_name,
  country_code, is_selected, traffic_limit_gb }`. Это полный список доступных серверов;
  для мультиселекта бери `squad_uuid` (значение) + `display_name` (подпись).
- **POST** `/admin/tariffs` (`TariffCreateRequest`) → принимает `limit_disabled_squads: string[]`
  (необязательное, по умолчанию `[]`).
- **PUT/PATCH** `/admin/tariffs/{id}` (`TariffUpdateRequest`) → принимает `limit_disabled_squads:
  string[]` (необязательное; если прислать — перезапишет список).

## Что сделать на фронте

1. В форме тарифа, рядом с блоком выбора серверов (`allowed_squads` / `servers`), добавить
   мультиселект **«Отключать при лимите трафика»**.
2. Варианты мультиселекта — это `servers` из ответа (подпись `display_name`, значение `squad_uuid`).
   **Ограничить выбор только теми серверами, что отмечены в `allowed_squads`** (нельзя гасить
   сервер, которого нет в тарифе). Если серверов в `allowed_squads` не выбрано — блок можно
   скрыть или сделать неактивным.
3. Предзаполнять из `limit_disabled_squads` при загрузке тарифа.
4. При сохранении отправлять `limit_disabled_squads` (массив UUID) в POST/PUT.
5. Если из `allowed_squads` убрали сервер, который был в `limit_disabled_squads` — убрать его и
   из `limit_disabled_squads` (не давать «повисшие» UUID).

## Подсказка для пользователя (текст рядом с полем)

Что-то вроде: «Когда пользователь исчерпает трафик, выбранные серверы временно отключатся, а
остальные продолжат работать. Серверы вернутся автоматически при сбросе трафика, докупке или
смене тарифа.»

## Не делать

- Не трогать логику `allowed_squads` / `server_traffic_limits` — это отдельные поля.
- Не добавлять никаких вызовов к RemnaWave напрямую — только поле в форме тарифа.
